# Stock Market Insights (2021–2025)

## 📊 Project Overview
End-to-end data pipeline for analyzing stock market trends across multiple sectors (2021–2025).  
The project focuses on identifying patterns in stock price movements using data engineering and analytics tools.

## 🎯 Business Problem
Analysis of stock price trends for selected companies across different sectors, with the goal of identifying patterns related to volume, volatility, and overall market behavior.

## 🧱 Architecture
Data pipeline built using:

- Python (data extraction via API)
- Azure Blob Storage (raw data storage)
- Azure SQL / Data Warehouse (structured data)
- dbt (data transformation)
- Power BI (data visualization)
- Orchestration (scheduled pipeline execution)

## 📈 Data Sources
- Stock market data via Yahoo Finance API (yfinance)

## ⚙️ Tech Stack
- Python
- SQL
- dbt
- Azure
- Power BI

## 📌 Key Features (planned)
- Automated data ingestion pipeline
- Data transformation using dbt (staging & marts)
- Stock performance analysis across sectors
- Dashboard with key financial metrics
